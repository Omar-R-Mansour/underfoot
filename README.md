# Underfoot

**Play in your browser: https://omar-r-mansour.github.io/underfoot/**

You're a flower in a sidewalk crack. The only way to spread is to get stepped on.
Aim with the mouse and click to duck, or on a phone (sideways) touch to aim and tap DUCK.
Made for the "Bounce Back" game jam.

This repository only holds the built game that GitHub Pages serves.
